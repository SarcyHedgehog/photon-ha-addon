# Photon HA Bridge add-on repository

This repository contains the Home Assistant add-on for Photon HA Bridge.

The add-on runs a private bridge between a Home Assistant installation and a
Photon Realtime room. It does not contain Home Assistant credentials, Photon
credentials, room passwords, or entity selections.

Add this repository in Home Assistant under **Settings → Apps → App Store →
Repositories**, then install **Photon HA Bridge**.

See the add-on documentation before exposing entities for remote control.
